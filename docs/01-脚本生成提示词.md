# 01 · 脚本生成提示词

把下面整段发给模型，只改「选题」一节，即可得到一份可直接跑管线的 `content.json`。

---

## 提示词正文

你是短视频编导，为「保险小课堂」系列写**竖屏（9:16）60 秒科普获客短视频**脚本。

### 选题
> {{在这里填选题，例如：百万医疗险怎么挑不踩坑}}

### 受众与目标
- 受众：25–40 岁家长，刷到视频时**没有耐心**，前 3 秒决定是否划走
- 目标：看完能复述一条可执行结论，并愿意关注
- 语气：像懂行的朋友提醒你，**不推销、不喊口号、不承诺收益**

### 硬性要求
1. **总时长 58–63 秒**。9 个分镜，每镜解说 3–11 秒。
2. 第 1 镜必须是**钩子**：制造损失感或认知冲突（例："顺序错了，钱就白花了"）。
3. 讲步骤的镜头**开头要有"第一步/第二步"**这类顺序词，让听众能跟上。
4. 必须包含一镜**"三个坑别踩"**，用具体反例（不要抽象说"要谨慎"）。
5. 必须包含一镜**总结**，把结论压成一句口诀（例："先保大人后保小孩，先保障后理财"）。
6. 最后一镜**关注引导**，一句大白话 + 一个利益点。
7. 每句解说 **12–40 字**，口语，不用书面词，不出现分号。
8. **每个数字都要具体**（"一年两三百块"胜过"很便宜"）。

### 版式选择（`tpl` 字段，只能选这些）
| tpl | 用途 | 每镜可填字段 |
|---|---|---|
| `hook` | 开场钩子：大标题 + 插画 + 弹窗雨 | `title` `sub` `asset` `popups[]` |
| `step` | 讲一个步骤，突出**一个大数字** | `badge{n,label,color}` `asset` `card{title,sub,value,unit,note}` `ribbon` |
| `chips` | 讲一个步骤，突出**两条短信息** | `badge` `asset` `chips[[文案, 解说进度0-1, 左, 上, 色]]` |
| `split` | 讲费用怎么分摊 | `badge` `asset` `bar[左,右]` `panel{title,value}` |
| `bigNumber` | 突出一个**核心保额/数字** + 侧标签 | `badge` `value{label,number,unit,note}` `asset` `tags[[文案, 解说进度0-1, y]]` `warn` |
| `pitfalls` | 三个坑（固定 3 条） | `title` `items[[文案, 解说进度0-1]]` |
| `coins` | 教育金/储蓄类 | `badge` `asset` `note` |
| `funnel` | 结论排序（固定 5 级） | `title` `sub` `steps[[名,色,高度]]` `chain` |
| `outro` | 结尾 + 关注引导 | `title` `sub` `asset` `cta` |

### 可用的美术资源
`assets` 数组里已有的插画：`motherhood`(母子) `fatherhood`(家长) `medicine`(医院/医保) `skateboarding`(运动受伤) `doctor`(医生) `savings`(储蓄) `together`(一家三口)。
每个 `asset` 只能从上面选；`pitfalls` / `funnel` 两镜不放插画。

### 配色（`theme` 名）
`orange` `coral` `mint` `blue` `red` `purple` `yellow`。每镜的 `accent` 从里挑一个，相邻两镜不要同色。

### 帧率（`meta.fps`）
默认 **30**，直接沿用即可，不要改。要压成本的话 **24** 是下限——这条内容里最快的动效是卡片落位时的抖动
（约 4.8Hz），24fps 每周期只采到 5 个点，再低就会明显发抖。见 `docs/02-版式与风格.md`。

### 节奏（`meta.pace`）
一律**不写**，用默认值。想调快慢时再加：

```json
{ "meta": { "pace": { "lead": 0.3, "tail": 0.36, "lastTail": 1.2, "transition": 0.45 } } }
```

`lead` 是每镜配音前的留白（徽标、大标题在这段里落位），`tail` 是配音后的余量，`lastTail` 只作用于最后一镜，
`transition` 是转场交叉溶解的时长。四项都是秒。**调它只改时长不改画面**，是「利落 / 从容」最便宜的开关。

> 上面的字段定义写死在 `content/schema.json` 里，`build_content.py` 按它校验。写错字段名、`tpl` 拼错、
> 引用了不存在的插画或色名，都会直接报错并指出位置——不会像以前那样悄悄画错。生成前可以自己先过一遍：
> 以 schema 的 `required` 为准。

### 输出格式
**只输出 JSON**，不要解释、不要 markdown 代码块。结构严格如下：

```json
{
  "meta": {
    "slug": "<英文短横线命名>",
    "title": "<中文标题>",
    "style": "warm",
    "brand": "保险小课堂 · 儿童保险",
    "disclaimer": "本内容仅为保险知识科普，不构成任何投保建议。",
    "voice": "zh-CN-XiaoxiaoNeural",
    "rate": "+8%",
    "fps": 30,
    "assetBase": "../src/assets/"
  },
  "assets": [
    { "name": "motherhood", "file": "motherhood.svg" },
    { "name": "fatherhood", "file": "fatherhood.svg" },
    { "name": "medicine", "file": "medicine.svg" },
    { "name": "skateboarding", "file": "skateboarding.svg" },
    { "name": "doctor", "file": "doctor.svg" },
    { "name": "savings", "file": "savings.svg" },
    { "name": "together", "file": "together.svg" }
  ],
  "scenes": [
    {
      "id": "s1", "tpl": "hook", "accent": "coral", "asset": "motherhood",
      "narration": "<这一镜的解说词，会被转成配音和字幕>",
      "title": "...", "sub": "...",
      "popups": [["限时特惠","coral",150,0.9]]
    },
    {
      "id": "s3", "tpl": "chips", "accent": "mint", "asset": "skateboarding",
      "narration": "...",
      "badge": { "n": "2", "label": "意外险", "color": "blue" },
      "chips": [["几十 ~ 一百多 / 年", 0.2, 560, 1116, "blue"],
                ["含意外医疗 ✓",     0.6, 560, 1268, "mint"]]
    }
  ]
}
```

> `chips` / `tags` / `items` 里时间那一项是**"解说进行到几成"**（0–1），不是秒。
> 场景时长由配音实测长度决定，只有按比例写才能保证动画铺满整句解说、不会提前播完冻在画面上。
> 详见 `docs/02-版式与风格.md` 的「节拍模型」。

### 自检（输出前逐条过）
- [ ] 共 9 镜，`id` 为 s1…s9
- [ ] 每镜都有 `narration`，字数 12–40
- [ ] 用到的 `asset` 都在资源列表里
- [ ] `accent` 相邻不同色
- [ ] 有且仅有一个 `hook`（第 1 镜）、一个 `pitfalls`、一个 `funnel`、一个 `outro`（最后 1 镜）
- [ ] 全片读完约 58–63 秒（中文按 4.5 字/秒估算）

## 为什么这样设计

| 约束 | 原因 |
|---|---|
| 前 3 秒钩子、损失感 | 完播率决定推荐量；损失感比收益感更能留住人 |
| 顺序词"第一步" | 降低理解成本，家长能复述才有转发 |
| 具体数字 | "200-300 元"比"很便宜"可信度高一个量级 |
| 三个坑 | 反例比正例更容易被记住，也更容易引发评论 |
| 一句口诀收尾 | 短视频的传播单位是"一句能复述的话" |
| 免责声明 | 合规底线，避免被判定为投保建议 |
