# 03 · 出片流程

> 一句话版本：`.\bootstrap.ps1 -Name "我的视频"` —— 装依赖、出片、校验全包，新环境直接跑。
> 下面是把每一步拆开看的样子。

## 一、依赖

| 组件 | 用途 | 备注 |
|---|---|---|
| Python 3.10+ | TTS、音频混音、编码 | 需要 `edge-tts`、`numpy`、`imageio-ffmpeg` |
| Node.js 18+ | 逐帧渲染、校验 | 需要 `playwright`、`sharp`、`tesseract.js` |
| Microsoft Edge | 渲染载体 | Playwright 用 `channel: 'msedge'` |
| ffmpeg | 编码 | 由 `imageio-ffmpeg` 自带，无需单独装 |

一句装好 —— 全部落进项目内 `deps\`，之后不用再配任何环境变量：

```powershell
.\install_deps.ps1
```

（想装到全局环境也行：）

```powershell
pip install edge-tts numpy imageio-ffmpeg
npm install playwright sharp tesseract.js
npx playwright install msedge
```

或直接复用已有的运行时目录——**一条命令搞定**（注意前面那个点）：

```powershell
. .\setenv.ps1
```

它会按 `-PythonPath` → 项目内 `deps\pylibs` → 已设的 `PYTHONPATH` → 常见缓存目录 的顺序探测，
并且**真的 `import edge_tts, imageio_ffmpeg, numpy` 验证一次**，通过才设 `$env:PYTHONPATH`；Node 侧同理。
也可以显式指定：`. .\setenv.ps1 -PythonPath "D:\deps\pylibs" -NodePath "D:\deps\node_modules"`。

（手动等价写法就是 `$env:PYTHONPATH = "<依赖目录>"` + `$env:NODE_PATH = "<node_modules 目录>"`。）

## 二、三步出片

```powershell
. .\setenv.ps1                 # 配依赖路径；不想管环境就直接跑 .\run.ps1（会自动加载 setenv）

# ① 内容 -> 时间轴 + 按需配音
python scripts\build_content.py content\child-insurance.json

# ② 逐帧渲染（1876 帧约 3.5 分钟）
node scripts\render_frames.js png

# ③ 编码
$env:OUT_NAME = "给孩子买保险-科普短片"
python scripts\encode.py
```

产物：`out/<OUT_NAME>.mp4`（1080×1920 / 30fps / H.264 High + AAC 192k）

两个环境变量可覆盖默认值：`OUT_DIR`（默认 `out/`，在项目内）、`OUT_NAME`（默认 `video`）。

> 懒人版：`.\run.ps1 -Name "给孩子买保险-科普短片"` —— 内容、配音、配乐、混音、渲染、编码一次跑完，
> 已存在的镜次配音和 `bgm.wav` 会自动复用。加 `-PreviewOnly` 只抽 6 帧看效果。

### 非 Windows：`scripts/pipe.py`

`run.ps1` / `setenv.ps1` 依赖 PowerShell。macOS / Linux 用 `scripts/pipe.py`，它自己配好
`deps/venv`、`deps/node_modules`、`RENDER_HTML`，步骤顺序与 `run.ps1` 一致：

```bash
python3 scripts/pipe.py check                                        # 依赖自检
python3 scripts/pipe.py build   content/child-insurance.json         # ① 同上
python3 scripts/pipe.py render  --frames-dir out/frames              # ② 同上
python3 scripts/pipe.py audio                                        # 配乐 + 混音
python3 scripts/pipe.py encode  --name "给孩子买保险-科普短片"          # ③ 同上
python3 scripts/pipe.py all     content/child-insurance.json --name 成片名   # 一次跑完
```

`preview --times auto` 从 `timeline.json` 里每镜取一点（解说进行到 65% 处），抽 6 帧铺满全片：

```bash
python3 scripts/pipe.py preview content/child-insurance.json --times auto --dir preview
```

## 三、各步骤在做什么

### ① build_content.py
1. **校验** `content/<x>.json`（按 `content/schema.json`）。有错就一次列全并退出——
   这一步在跑 TTS 之前，所以写错字段不会白等几分钟。
2. 对每镜 `narration` 取 MD5，和 `tts/_hash.json` 比对：
   - 命中 → 复用 `tts/<id>.mp3`
   - 未命中 → 调 edge-tts 重新合成
3. 用实测音频时长排时间轴：`start / dur / speechStart / speechDur`
   （镜间留白 0.30s 入 + 0.36s 出，末镜尾部 1.20s；四项都可由 `meta.pace` 覆盖）
4. 产出三个文件：
   - `engine/content.js` —— 内容 + 皮肤 + 时间轴，供渲染读取
   - `timeline.json` —— 给 Python 侧用
   - `src/timeline.js` —— 给浏览器用（含 `window.PACE`，节奏从这里进引擎）

> 改文案后**不需要**手动调任何时间，字幕与动画节奏会自动跟着走。

### ② render_frames.js
用 Playwright 打开 `engine/render.html`，等 `window.__assetsReady === true`（7 张 SVG 异步加载完），
然后逐帧调用 `window.renderFrame(t)` 并截图。默认输出 `out/frames/f00000.png …`。

- 预览只抽几个时间点（省时间）：
  ```powershell
  node scripts\render_frames.js preview '[1.5,10.3,20.0,45.5,58.5]' mypreview
  ```
- 新引擎做回归比对时输出到别处，避免覆盖：
  ```powershell
  $env:FRAMES_DIR = "out/frames_v2"
  ```

### ③ encode.py
```powershell
ffmpeg -framerate 30 -i out/frames/f%05d.png -i audio.m4a \
  -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p -profile:v high \
  -x264-params keyint=60:min-keyint=30 \
  -c:a aac -b:a 192k -movflags +faststart out/<名>.mp4
```

## 四、音频（只在需要时重做）

```powershell
python scripts\make_bgm.py     # 合成柔和背景音乐 -> bgm.wav
python scripts\mix_audio.py    # 配音 + BGM（自动闪避）-> audio.m4a
```
`mix_audio.py` 在解说出现时把 BGM 压到 38%，说话间隙恢复，避免盖住人声。

## 五、并行与断点

- 渲染耗时与帧数成正比，改文案后帧数会变，**必须整片重渲**（时间轴变了）
- 只改皮肤（`styles/*.json`）同样要整片重渲，但不需要重做配音（`build_content.py` 会全部命中缓存）
- 只是调字幕样式 → 改 `engine.js` 的 `drawSubtitle()`，然后重渲
